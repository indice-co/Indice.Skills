# Indice.Skills

Shared AI skills and instructions for the Indice organization.

## Repository layout

Each skill lives in its own directory under [`skills/`](skills/), with a
`SKILL.md` file that describes its purpose, instructions, and usage.

## Adding a skill

1. Create `skills/<skill-name>/SKILL.md`.
2. Use lowercase kebab-case for the directory name.
3. Include a concise description, the instructions, and any required inputs or
   tools.
4. Add the skill to the [skills catalog](skills/README.md).
